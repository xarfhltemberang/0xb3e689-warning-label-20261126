# Warning Label for Humans: One Line, Big Laugh

A single-line safety warning label that should come printed on every human
being — funny first, plausible second, 160 characters or fewer.

## Entry

> WARNING: This human read the instructions, understood the instructions, and will now ask you what the instructions said.

The joke is recognition: everyone has met (or been) the person who insists
they read and understood the instructions, then immediately asks what the
instructions said. The triple repetition of "the instructions" gives it the
flat, procedural rhythm of a real printed label, and the turn lands in the
last few words.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` with no trailing newline.
Python 3 standard library only; no dependencies, no network.
